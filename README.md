## 📋 Descrição do Projeto
Neste projeto, utilizamos um **ESP32** para [controlar as Funcões do capacete].

## 🛠️ Materiais Utilizados
* 1x ESP32-S3
* Display OLED
* 👀 SERVO ULN 2003
* 🎤 Microfone INMP441
* 🔊 Amplificador MAX98357A

## 🚀 Como baixar e usar?
